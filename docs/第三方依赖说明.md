# 第三方依赖获取说明

## LibreHardwareMonitor（CPU 温度传感器）

SysMonitor 使用 LibreHardwareMonitor 读取 AMD CPU 温度（Tctl/Tdie），需要管理员权限。

### 获取步骤

1. 从 [LibreHardwareMonitor GitHub Releases](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases) 下载最新 `LibreHardwareMonitor-net*.zip`
2. 解压到 `LibreHardwareMonitor/` 目录
3. 核心文件只需 `LibreHardwareMonitorLib.dll`（约 1.2MB），其余 DLL 是 UI 依赖可不放
4. 用 `lhm_dump/compile.bat` 编译 `lhm_dump.exe`（需要 .NET Framework 4.x，Windows 自带 `csc.exe`）

### 手动编译

```cmd
:: 进 LibreHardwareMonitor 目录，把 lhm_dump.cs 放进去
csc.exe /nologo /target:exe /out:lhm_dump.exe /r:LibreHardwareMonitorLib.dll lhm_dump.cs
```

`csc.exe` 位于 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\` 或 `Framework\` 下。

## PresentMon（FPS 帧率）

FPS 功能通过 Intel PresentMon 的 ETW 模式抓取当前前台进程的帧率。**这是可选功能**，不放 PresentMon.exe 则 FPS 栏不显示，其余功能不受影响。

### 获取步骤

1. 从 [Intel PresentMon GitHub Releases](https://github.com/GameTechDev/PresentMon/releases) 下载最新 `PresentMon-*-x64.exe`
2. 重命名为 `PresentMon.exe` 放到源码目录下

### 工作原理

SysMonitor 启动 PresentMon 子进程：
```
PresentMon.exe --output_stdout --no_console_stats --session_name sysmon --stop_existing_session
```
解析 CSV 流，按进程名计数最近 1 秒内的帧数，过滤掉浏览器/终端/Explorer 等非游戏进程，显示帧数最高的进程的 FPS（≥10 帧才显示）。
